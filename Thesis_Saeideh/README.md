# Thesis_Saeideh

This folder is reserved for thesis Word documents and their Git history.

Suggested naming pattern:

- `thesis_v01.docx`
- `thesis_v02.docx`
- `chapter1_v01.docx`
- `proposal_v01.docx`

Recommended workflow:

1. Put each new Word file or revision in this folder.
2. Use a clear version in the filename.
3. Commit each meaningful update to Git so the history stays easy to find.

Example commit messages:

- `docs: add thesis v01`
- `docs: update thesis to v02`
- `docs: revise chapter 1 draft`
